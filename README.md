# paintluzacarrillo
Proyecto de paint Luz Angelica Carrillo
Arquitectura:

Inicialización: configuración de la ventana, OpenGL y librerías.
Interfaz gráfica: panel de herramientas y paleta de colores mediante Dear ImGui.
Gestión del lienzo: matriz bidimensional que almacena los colores de cada celda.
Entrada del usuario: procesamiento de las interacciones del mouse.
Algoritmos de dibujo: Bresenham, punto medio para circunferencias y Flood Fill.
Selección y rotación: gestión de figuras seleccionadas y transformación mediante funciones trigonométricas.
Renderizado: generación de vértices y representación del lienzo mediante shaders y buffers de OpenGL.
